Everything New On Windows 11 (Gaming Excluded)

Windows 11 has been officially launched. Even though it has been leaked, some of the awesome features were not there on the leaked version. This article is all about the new features of Windows 11 (Gaming Excluded).

Design

Microsoft this year, tried their best in copying apple’s MacOS 11 Bigsur or Monterey, including the name of the OS. This year the taskbar is in the center, you can still change the alignment. Everything is a bit curved, the corners are curved for app windows, start menu and everything else. All of windows feels glassy just like Windows vista. The start menu is now a floating window. The file explorer got a pretty nice looking redesign. The Microsoft store got a complete redesign from the ground up. Overall Microsoft has tried their best to make Windows 11 look like Mac OS.

Features of Windows 11

Again more macOS like. Windows 11 will wakes up from sleep more faster. Windows 11 promises 40% smaller updates (FINALLY). Microsoft said that Windows 11 is the most secure version of windows ever. Windows is more power efficient, it is also said to be more faster. There is a new minimalistic startup sound. Windows 11 will run only on 64 Bit devices, 👋🏻 32bit. There is a new minimalistic startup sound.

Microsoft edge has vertical tabs like the ones on Vivaldi Browser. Web browsing is faster on all the browsers, not only on edge but also on other browsers. When you hover over the maximize button you can see a lot of alignments for multi tasking. Windows remembers the alignment of apps, just like the ones on iPad OS. Features a whole new widget section. In the start menu there is a new cloud recommendation section wherein it displays apps and files that you might be interested in, this feature is entirely powered by AI.

There is this new dual monitor feature, when you unplug your laptop from an external monitor the apps that were opened on your monitor would minimize on your laptop, when you plug it again to the monitor the app automatically opens up on the monitor. There is a new universal mute button. In Windows 11 you can create custom desktops. Overall, the features are not bad.

Software and Apps

Teams is now fully integrated onto Windows 11. Something that I’m dying to try out on Windows 11 is to install Android apps onto Windows 11 via the amazon store. This is a feature that is already there on Mac OS. Microsoft allows developers to easily upload their apps on to the Microsoft store. Now, it’s easy for developers to put there apps on to Microsoft store. Overall pretty dope.

Final Verdict

In the end, I think Windows 11 is great, it doesn’t have a lot of new features and I think Windows is more geared on people who use Windows for work and not Gamers. Anyways it is better from compared to windows and I am dying to get my hands on one.
